# Packs utilisés

Deux packs restent branchés au jeu :

| Dossier | Rôle |
| --- | --- |
| `thug-16bit-outlined/` | Sprites du combat (Idle, Walk, Run, Attack1–4, RunAttack, strafes, dégâts, mort) |
| `fantasy-cc/` | Planches du créateur de personnage (`character-creator-fantasy.html`) |

Les packs de calibration (knight, x180, mannequin, survivor) et les pages de réglage d’orientation ne font plus partie du dépôt : le jeu ne propose plus que le combat, le créateur et l’éditeur de sorts.
